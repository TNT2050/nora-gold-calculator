# YOUSEF IO

نسخه وب دستیار تحلیل و مدیریت معامله، با رابط فارسی و طراحی واکنش‌گرا.

## امکانات فعلی
- نمودار کندلی و داده‌های عمومی Binance Spot و Futures
- انتخاب نماد و تایم‌فریم
- EMA 20/50، RSI 14 و حجم
- خوانش سریع روند، مومنتوم و سطوح تقریبی حمایت/مقاومت
- سناریوهای لانگ/شورت/عدم ورود
- محاسبه بودجه ریسک و اندازه تقریبی موقعیت
- بررسی تاریخی ساده و هشدار قیمت در زمان باز بودن صفحه

## انتشار
این پروژه در مسیر `YOUSEF-IO/` قرار دارد. گردش‌کار GitHub Pages از همین پوشه خروجی وب می‌سازد.

## محدودیت‌ها
- داده‌ها از API عمومی Binance دریافت می‌شوند و در صورت محدودیت شبکه یا API ممکن است در دسترس نباشند.
- تحلیل فارسی در این نسخه بر اساس قواعد تکنیکال داخل مرورگر است، نه مدل هوش مصنوعی متصل به سرور.
- بک‌تست فعلی ساده و آموزشی است و هزینه معامله، اسلیپیج و اجرای واقعی را مدل نمی‌کند.
- هیچ سفارش معاملاتی ارسال نمی‌شود.
- این ابزار توصیه مالی نیست.
