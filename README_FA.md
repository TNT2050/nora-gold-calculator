# ماشین حساب طلای نورا — نسخه اندروید

این پروژه، صفحه ماشین‌حساب فارسی را داخل یک برنامه مستقل اندروید (WebView) اجرا می‌کند و برای کار آفلاین طراحی شده است.

## ساخت خودکار APK با GitHub
1. تمام محتویات این پوشه را در ریشه مخزن `TNT2050/nora-gold-calculator` بارگذاری کنید و فایل‌های هم‌نام را جایگزین کنید.
2. در GitHub به زبانه **Actions** بروید.
3. گردش‌کار **Build Nora Gold APK** را باز کنید و **Run workflow** را بزنید (یا منتظر اجرای خودکار پس از push بمانید).
4. پس از سبز شدن اجرا، از همان اجرای workflow بخش **Artifacts**، فایل `NoraGold-debug-apk` را دانلود کنید.
5. ZIP آرتیفکت را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

شناسه برنامه: `ir.noragold.calculator`
حداقل اندروید: 6.0 (API 23)
